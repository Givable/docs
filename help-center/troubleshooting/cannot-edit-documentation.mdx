---
title: Cannot Edit Documentation
description: Fix edit permission issues in Givable.
---

## Symptoms

- You see a lock icon on pages
- Edit button is disabled

## Possible Causes

- Insufficient permissions
- You are not logged in

## Solution

<Steps>
  <Step title="Check login">
    Ensure you are logged in to your Givable account.
  </Step>
  <Step title="Verify permissions">
    Ask a project admin to grant you edit access for the space.
  </Step>
  <Step title="Refresh page">
    Log out and back in if changes do not appear.
  </Step>
</Steps>
