## Overview

Givable empowers nonprofits to streamline online fundraising with intuitive tools. You can create customizable donation forms, launch engaging campaigns, and foster recurring donations to maximize donor retention and revenue. Built specifically for mission-driven organizations, Givable integrates seamlessly with your existing tech stack.

## Quick Start

Get up and running in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create your free account at [givable.com](https://www.givable.com).
  </Step>
  <Step title="Create Your First Form" icon="edit-3">
    Use the form builder to design a donation page. Customize branding and add a recurring upgrade option.
  </Step>
  <Step title="Embed and Share" icon="share-2">
    Generate embed code for your website or share campaign links via email and social media.
  </Step>
  <Step title="Connect Integrations" icon="plug">
    Set up webhooks or native integrations to sync donations with your CRM.
  </Step>
</Steps>

<CodeGroup tabs="HTML,React">
  ```html
  <div id="givable-form"></div>
  <script src="https://js.givable.com/embed.js"></script>
  <script>
    GivableEmbed.init('your-form-id', 'YOUR_API_KEY');
  </script>
  ```
  ```jsx
  import { GivableForm } from '@givable/react';

  function DonationForm() {
    return (
      <GivableForm
        formId="your-form-id"
        apiKey="YOUR_API_KEY"
      />
    );
  }
  ```
</CodeGroup>
